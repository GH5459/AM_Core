# 安裝

先完成完整CI與PR審查合併。以本人建立的五個原專案聊天及API目前五專案ID建立私人對照，逐一驗證原生派送及實際回覆，不能用業務事件測寫。桌面執行上下文使用授權接線者本聊天，不借用他案身分。

確認原接收器無案件執行中後，備份原bridge與設定及新增模組的檔案存在狀態。重讀最新正式本機設定，保留Git／PR工具、prompt、秘密及其他欄位，只增加visibleChatsFile。安裝合併來源的bridge與visible-chats模組，再重啟原接收器一次。保留原啟動登記，不新增程序或定時AI。

驗證原事件連線恢復、沒有閒置AI或queue讀取，完整操作及雜湊留私人目錄。正式服務與既有案件不需遷移。桌面或原工具不可用時沿原事件回報受阻，不退回隱藏CLI、不自動重送不明結果。
