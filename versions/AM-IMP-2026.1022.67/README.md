# 五專案專用案件聊天

Ready。本人要求在目前五個服務專案各建立「葉小蝸處理案件」聊天，並讓原事件接收器透過已安裝的官方桌面工具接續。原事件、案件、方案、建議與核准資料不遷移、不重寫；不重放已啟動或結果不明的事件。

只有正式回報、有效補充、主管建議、當版核准等原服務事件才派送。依API當前精確專案ID匹配私人設定的聊天；未分類分析先在原AI小助手專案釐清。聊天移動、分類改變、來源或核准失效即停止。分析只准寫私人證據，執行仍須原API本人當版核准、claim和每次副作用前check。專用聊天依最新專案規則隔離修改，並顯示實際進度與受阻原因。

接收器僅在本次事件期間確認該聊天是否結束，不查業務queue、不啟動額外AI。提出釐清或方案、完成或受阻後結束；等待使用者時不持續AI。原生聊天無強制中斷工具，因此失效時由API守衛拒絕後續副作用，聊天指令要求即刻停止，不以停止讀取冒稱已取消執行。

本項只安裝本機接收器，不發布AM、DailyLog、UOF或HOZO雲端程式。不增加排程或恢復heartbeat。不更動真人身分、權限、綁定、原LINE或業務資料。私人聊天對照與桌面連線資訊不得進Git。
