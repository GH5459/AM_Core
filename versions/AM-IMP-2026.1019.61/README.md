# Lunar annual and all-day calendar

Normalizes whitespace and full-width digits in date input while preserving source evidence. Annual lunar dates are computed deterministically in Taiwan timezone and stored as one native Google Calendar RDATE series. All-day anniversaries require no invented time. Explicit unsupported requests receive an explanation; unresolved identity receives setup guidance. Original owner confirmation, cancellation and replay protection remain mandatory.

Supported lunar years: 1901–2100. Confirmation states the finite horizon. Regular months exclude leap months; requested leap months and missing day 30 skip years without that date. No silent conversion to Gregorian annual rules.

Scope: root OA and its configured original DailyLog; no automatic standalone project installation or data migration.
