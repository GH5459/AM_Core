# 發布中的會議沿用正常觀看版

發布中或等待背景續作時，原畫面仍選擇編輯模式，卻又鎖住內容並隱藏模式切換，導致使用者看見 `##` 與全部展開的對話文字。
標題與分層收合程式沒有遺失；這是 publishing 狀態選錯顯示路徑。

本次讓發布中使用既有觀看版，保留主題、結論、子題及對話依據的收合；自動讀取保留使用者展開的區塊。
發布狀態、錯誤及等待提示仍如實呈現，不把發布中標成已完成。正常共同編輯及發布後手動切換編輯保持。
隱藏的發布設定仍更新鎖定狀態，避免保留過時的可操作控制項。

不修改會議原文、Markdown、段落 ID、修訂、任務、音檔、分享、同步工作或原服務設定，也不重送 LINE。
