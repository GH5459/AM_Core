# 群組 mention 會議與任務

原本群組會議被私人行事曆入口排除，未確認工作身分的 mention 任務則直接略過。新增從原始 webhook 證據接續的群組流程：明確邀約先由發起人確認，再逐人建立 Google Calendar 活動；明確交辦送入既有受派待辦與交辦人紀錄。

原始來源保持在 OA 自己的 central_archive；待處理標記保存在原來源 JSON 的 groupDispatch。使用既有本人公司登入、Google 授權、服務配置，不匯入客戶資料、不更改業務群組歸屬。資料、登入、連線未齊保留 30 天並自動重試。一般問候、查詢及已結束回顧不建立。

每個人獨立建立一份活動，並非 Google 共用邀請／RSVP；後續 Google 編輯不會跨份同步。卡片僅原發起人可操作，補充使用文字，改版後舊按鈕失效。日期時間是建立門檻；模糊或缺漏地點可保留。
