# Install

1. Snapshot the target's latest active immutable version, all modules, settings, schedules and uploaded etag privately. Stop and rebase if production advances. Do not build the dirty checkout.
2. Add the preview endpoint module, gallery client and CSS response transformation from reference. Wrap the current default worker, preserving every existing wrapper and scheduled handler. Verify exact asset anchors against current authorized asset responses.
3. Only alter worker entry and add the image module; retain all other module bytes. Preserve current Assets with keep_assets. The public folder used by tests is a fixture and must never be uploaded.
4. Run full-worker authorization/bytes tests, six browser widths, read-only viewer, failure retry, draft preservation, sharing/deletion and current collaborative completion regressions.
5. Recheck current version and settings immediately before upload/deploy. Verify exact source hashes, all bindings/secrets/services/vars/compatibility and schedules after release. Save receipts only in original private target storage.

No task/message writes or real photos are needed for deployment testing. Do not deploy AM runtime, UOF or other OAs for this UI change.
