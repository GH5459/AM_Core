# 工作會議週期與待辦預設到期日

狀態：Ready。程式與本機驗證已完成，正式環境尚未部署。

內建類型改為工作會議、電話、討論、主題研討；月會改為工作會議的週期。工作會議提供日會、週會、月會、自訂天數及單次／不固定。

以本次會議日期為基準：日會當天、週會加 6 天、自訂 N 天加 N−1 天；月會以下個月同日作下次會議日，不存在該日時取月底，再減一天。可選填確切下次會議日期，優先採用其前一天。新工作頁預設工作會議／日會，畫面即時顯示計算結果。

AI 產生候選與手動新增待辦使用同一計算。沿用既有模型日期文字留在來源依據、由成員確認日期的流程；本包不增加依模型日期自動覆寫的行為。手動修改與已保存日期不重新計算。

舊會議、月會只在未製作工作頁的設定畫面提供新版選項，按儲存才寫入；舊會議沒有週期時顯示單次／不固定。已發布內容不批次改名或改期。不新增任務、不重播錄音、不改分享權限。
