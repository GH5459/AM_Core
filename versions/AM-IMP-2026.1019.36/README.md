# 重點與決議及可展開的對話依據

將同一議題的摘要、結論與下一步整合，觀看時先讀精簡結果，展開才顯示講者、來源時間與對話摘意。新製作採用相同規則；原待辦、期限、錄音、完整逐字稿與原權限保持。

共用實作在 `modules/meetings/decision-record.js`，契約為 `meeting-decisions-with-evidence-v1`。內容仍是可版本編輯的純文字，不儲存未經清理的 HTML。網頁與 Notion 顯示同一組議題及依據。舊格式保持可讀，不批次重寫。

原始業務內容、正式識別碼、私人快照與傳送收據不可進入本套件。實際目標是原 AM 平台；HOZO_AM／SevenAM 不在本次安裝範圍。
