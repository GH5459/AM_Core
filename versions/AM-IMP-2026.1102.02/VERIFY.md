# 驗證

只跑受影響的指令、日期、任務傳輸、補充、原身分及錄音入口相關測試。新建命令使用正常 LINE mention 位置；歷史佇列另用已封存的原來源驗證，避免把舊入口當新入口。

必要項目：三個關鍵詞、無關鍵詞不建檔、多人、本人、48小時及跨年、補充不重算期限、補齊活動、自動一小時、原權限與撤回、雙送與重新啟動、錯群與錯人、舊卡逾時、部分失敗及原收據。

工作日誌使用真正 workerd/D1 與最新完整正式模組的隔離副本，驗證原任務、協作、回覆修改、取消、版本衝突、撤權及原子收據。正式只查版本、設定、模組及匿名邊界，不建立真人業務資料。

CI 只在本次精確檔案清單內選取上述測試；若同一 PR 含其他程式，原完整驗證流程照常執行。
