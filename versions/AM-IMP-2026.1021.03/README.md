# 錄音確認優先回覆

收到錄音後，先保存來源與可恢復的會議事件，再立即送出原本的「是否建立會議記錄」卡片。
不再排在其他會議恢復、日曆同步、姓名與單位查詢後面。只有本次事件涉及且尚無設定的對話需要初始化，避免每次掃描所有設定並等待無關設定鎖定。
背景恢復不再同時持有外層會議佇列連線與內層任務派送鎖；已在三條連線的限制下重現並排除連線耗盡。遠端建立會議庫亦改在外層佇列連線釋放後執行，仍保留原設定列鎖及各工作自己的防重複保護。

錄音仍沿原附件流程保存；卡片不代表音檔已完成保存或整理。原主持人同意、草稿、發布與指派權限保持。
傳送失敗保留原事件與工作頁，依原重試鍵恢復；不重播歷史錄音、不補發既有卡片。
姓名在後續處理或本人確認時補上，不用查詢姓名阻擋第一個回覆。

增加不含訊息內容或身分的接收耗時紀錄，區分訊息到達前、來源保存及會議接收的等待。
套件不含真人訊息、帳號、群組識別碼、錄音或機密設定。HOZO_AM／SevenAM 獨立服務仍須分別評估安裝。
