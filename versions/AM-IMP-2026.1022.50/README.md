# 葉小蝸 AI 秘書試行

沿用既有葉小蝸LINE OA，不新增OA或真人登入。右側第四格「回報問題」以postback收合選單，詢問問題並提供「完成回報」「查看我的案件」。同仁可分段說明／傳圖，先存私人草稿，按完成後才整理標題、文字與原圖，建立一張DailyLog工作卡。葉小蝸的內部工作身分參與四個既有專案；指定負責人核准目前方案版本後才領取執行，完成後回報原同仁、等同仁確認，並留下事實工作日誌。

工作日誌導覽提供「我回報的問題」，使用同一份工作主檔及本人權限；案件頁可補文字／圖片並看狀態與歷程。LINE連續補充保留24小時，每次最多100段、10張合計10MB；超過後先完成再接續原卡，網頁可持續補充。撤回草稿訊息不帶入正式卡；來源／方案補充失效舊核准。圖片題會先標示待釐清，不猜圖中內容。

狀態：Ready，正式狀態以原目標發布及回讀紀錄為準。使用者已於2026-10-22要求實作試行、建立帳號與加入四個既有專案；必要試行安裝在本項範圍內，其他候選與各業務權限不擴大。

AM：`core/xiaoye-secretary.js`、`core/leaf-tasks.js`、`server.js`。DailyLog：`core/xiaoye-secretary-dailylog.mjs`、UI及增量SQL，由`tools/build-xiaoye-worker.cjs`精準延伸真正最新完整包。私人帳號／專案ID／憑證只留原目標。
