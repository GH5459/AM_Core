# Install

Install only after full current-head CI and the original case's valid release authorization. Preserve complete latest AM, DailyLog and UOF packages and settings privately. Deploy the compatible AM broker first, then UOF and DailyLog extensions. Use build-worker.cjs against the actual latest complete modules, retaining the existing default wrapper, Assets, bindings, secrets and schedules; never build a dirty repository root. Exact source and anonymous boundaries must be read back before marking Deployed. Native UOF authorization and meeting membership remain mandatory.

Before deploying the broker, run `node tools/migrate-login-continuation.mjs <original-private-project-folder>` with the existing database owner configuration. It installs only the three login tables and grants their required operations to the existing runtime role. The runtime must not create tables or gain schema CREATE rights. Login fallback retains the original target and returnTo/ReturnUrl; update the current menu meeting URI in place while preserving its other areas and image. A direct owner release instruction is valid authorization; do not reuse an expired background event lease.
