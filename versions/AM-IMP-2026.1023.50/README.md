# 登入接續候選核心

狀態：Proposed，未接入任何正式或本機服務入口，不能發布為完整功能。

目前提供60秒一次兌換、指定目標與瀏覽器挑戰、原登入期限上限、原session與帳號及權限重核、登出停止整條接續鏈的核心。PostgreSQL儲存使用獨立表及單一DELETE RETURNING，不改原業務表。

來源與功能資格介面要求明確區分原生與接續登入，避免循環授權；UOF工作資格不製造SOAP或附件授權，會議仍需雙向確認映射及原成員檢查。

尚未完成三站HTTP/RPC接線、真實來源查核介面、瀏覽器導頁與cookie，以及完整整合測試。純函式測試不能取代這些驗收。本候選未import到server.js或任何Worker，不影響原流程。
