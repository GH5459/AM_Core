# 會議工作頁與發布鎖定

沿用會議開關。新錄音先詢問上傳者，按是後在原對話提供同一個工作頁。設定會議類型／自訂 Prompt／日期／主題／A、B、C 姓名與男女性別後，主持人開始製作；先產草稿，不先寫 Notion 或建正式任務。

產出後依序為會議記錄與待辦事項。來源對話目前有效成員可共同編輯，顯示姓名、顏色、欄位及修改紀錄。同欄位衝突保留本機輸入，使用者比較後決定，不靜默覆蓋。這是欄位協作，不宣稱逐字游標同步。

主持人固定為錄音上傳者，只有主持人可確認最新版本並發布。發布開始即永久鎖定，同一 URL 轉為唯讀記錄；伺服器拒絕所有舊頁寫入。不選負責人只留會議待辦；選了負責人必填截止日，並以既有本人綁定建立工作日誌個人任務。會議記錄固定保存發布當時內容，任務進度在工作日誌追蹤。

移除新後台的三種待辦模式。舊資料欄位及舊進行中確認保留相容，新工作頁不依該模式判斷。不重播歷史錄音、不補建歷史任務。原始音檔只引用原對話 Drive，正式文字保存到原對話 Notion 庫。

程式、結構與驗證位於 `modules/meetings/workspace*`、`dailylog-assignment.mjs`、`dailylog-workspace.sql`、`core/leaf-tasks.js` 與 `tools/test-meeting-workspace*`。正式連線、識別碼、名單、錄音與發布收據只存部署私人目錄。
