本聊天已直接授權實作、驗證及正式部署本功能，不沿用歷史案件核准或租期。

1. 從兩原目標下載最新完整正式模組、版本與配置，核最新上傳與100%版本一致；私人保存回退及原資料比對。
2. 在乾淨隔離來源套用 build.cjs，輸入包含 dailylog、uof-line-cloud 的私人 baseline/candidate 目錄。只改明確片段；找不到唯一片段即停止，不全量 build dirty 根。
3. 完整 Worker/D1/加密 UOF 與具名 RPC、原簽核流程及六寬 Chrome 通過，PR 精確版本完整 CI 通過後合併。

5. 保留所有秘密、Assets、bindings、相容設定、兩端排程與原 DO；回讀全部模組 bytes、100% 版本、匿名界線及本人原頁唯讀結果。
