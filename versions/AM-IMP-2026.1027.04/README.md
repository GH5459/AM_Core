# UOF 待簽剩餘時間

緊急、急件、普通件從目前本人簽核關卡收到時間起，分別限 24、48、72 個連續小時。剩餘 ≤24 小時為紅、>24 至48小時為橘、>48至72小時為綠；逾期仍紅並標明逾期多久。缺時間或未知等級顯示待確認。

DailyLog 沿原四分類加入三色筆數、逾期子集合及最早一筆剩餘時間；顏色連結直接進入原 UOF 分類與時間篩選。原 UOF 列表及原生入口頁每筆加入顏色、倒數、原等級與台北時間截止資訊。列表依截止時間排序；倒數更新不重建開啟的內容或操作佇列。

僅擴充既有唯讀查詢的 URGENT_LEVEL 回傳，不變更資料表、員工、授權、簽核 ticket、核准 API、防重、通知或排程。跨站讀取仍採原本人驗證及回傳前重核。完整正式來源留原目標私有資料夾；共享套件不得包含真人資料或設定。

原瀏覽器首次跨站可能未帶同來源登入 Cookie；接續登入及原登入備援須保留原 `/Line/Review` 的分類與顏色查詢，不回到預設全部分類。沿原同來源與允許路徑檢查，不放寬權限。已安裝本功能的目標可只用 patch-review-return.cjs 精準更新原 login-continuation-worker.mjs，不重發其他模組。
