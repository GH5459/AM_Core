# 工作日誌會議分頁讀取改善

狀態：Ready。使用者回報從工作日誌按「會議」分頁仍然慢，本包只改善此入口的清單讀取，保留原清單排序、分頁、來源、資料與權限。

正式入口已內嵌會議畫面，首次清單只等待一個 POST。改善前同帳號獨立分頁的清單可見時間為 9,085、7,306、14,732 ms，中位數 9,085 ms；另一筆只有網路完成時間 9,085 ms，沒有混入可見時間。這是已有登入與程式快取的桌面內建瀏覽器測試，不代表未登入或手機冷啟動。

本包減少清單身分查核中沒有使用到的完整登入回覆組裝，並將後端原本連續的身分與有效同仁查詢合成一次受保護的服務往返。兩步仍依序讀取最新資料，原第一層及後續的綁定守衛、CSRF、雙向對應、簽章與防重播保持。沒有跨請求權限快取，也不先顯示尚未通過權限核對的舊清單。

新增只含固定名稱與數值的耗時資訊，用來分辨工作日誌核對、服務往返與會議清單讀取。所有正式速度結論須在發布後以相同操作實測；隔離測試與正式結果分開紀錄。

完整現場程式、設定與資料快照只留私人發布目錄。安裝與回復順序見 INSTALL.md、ROLLBACK.md。
