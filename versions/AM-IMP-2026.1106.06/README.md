本包維持原核權時點，不新增等待 AM 回覆後的核對。既有同仁名單同步有 60 秒記憶；隔離測試確認原版與新版行為相同，因此不能宣稱任何進行中的撤權都會立即中止。

新增只含固定名稱與數值的耗時資訊，用來分辨工作日誌核對、服務往返與會議清單讀取。所有正式速度結論須在發布後以相同操作實測；隔離測試與正式結果分開紀錄。
