# 驗證

- 正常、到期、停用、未綁定、撤權、錯誤 CSRF、雙向帳號不一致均符合原行為；最外層拒絕不能被內部窄身分蓋過。
- 外部偽造標頭不能啟用內部能力；每個 Request 的能力不外流、不跨請求重用；多語系仍讀最新設定。
- 合併服務讀取維持身分後再讀同仁資料的順序、原服務驗證與租戶邊界；不支援、失敗及撤權皆拒絕，不靜默降級。
- 只有嵌入式 hub 清單啟用新路徑；其餘建立、儲存、刪除、發布、錄音、單場與分享操作保持。
- 原清單內容、順序、分頁與回覆內容等價。已部署的新增任務表單、會議手動重做及其餘並行改善保持。
- 完整 Worker 隔離測試、原回歸、六寬與完整 CI 通過；正式程式與選定資料回讀通過後才稱 Deployed。
- 正式速度改善前基準：可見清單 9,085／7,306／14,732 ms，中位數 9,085 ms。發布後結果另附，不能以減少呼叫數代替速度驗收。

原始現場資料與憑證不放入共享儲存庫。資料快照的涵蓋範圍須在實際結果中明確說明。
