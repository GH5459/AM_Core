# Recurring LINE calendar activities

Recognize 禮拜／星期／週 and preserve DAILY, WEEKLY and MONTHLY structured recurrence from source, confirmation and durable retries through the existing DailyLog machine API. Google receives one native event series, not separately generated occurrences. The first occurrence, interval, selected weekdays and optional inclusive until/count are displayed before the owner confirms. Unclear rules remain needs_details; one-off fallback is forbidden.

Scope: root AM Platform and the already configured DailyLog calendar service. No installation into other OA credentials or legacy standalone bots. No source replay or user event creation occurs during deployment.
