# 首次工作日誌登入自動識別 LINE 同仁

Leaf private entry issues a ten-minute opaque ticket. The original successful company login establishes a work-only native LINE/account identity. Current DailyLog access is required; UOF approval roles and manual pairing codes are not required. Group assignment uses this identity or an existing confirmed legacy identity, with exact live group membership and current work access.

An unknown LINE identity requires fresh company authentication. Browser cookies and display names do not establish it. Conflicts fail without overwriting either side. The original UOF bindings, grants, task history, archives and Calendar remain unchanged. This package applies only to the original Leaf OA and its configured DailyLog service.

Deployment and synthetic validation are distinct from the first real coworker login and mention acceptance.
