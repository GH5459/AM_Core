# Contract signing LINE initialization

Preserve a directly opened signing fragment in session storage without changing the URL, initialize LIFF, then read any fragment restored by LIFF before requiring the signing token. This covers two simulated initialization and navigation paths. It does not establish why any particular mobile device lost its link and must be verified on the affected device before declaring the incident resolved.

Existing group membership, signer authorization, token validation, and signing workflows remain in force. The token remains out of query strings, logs, and response bodies.
