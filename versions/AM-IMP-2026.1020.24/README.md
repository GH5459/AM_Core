# 發布前改選 LINE 對話群

狀態：Deployed。

主持人可於設定、製作中、確認中或製作失敗時，獨立選擇並儲存發布對話。名單限同 OA、同單位且主持人／葉小蝸目前仍在內的 group／room；原來源可作為恢復選項。目的群不必開啟錄音整理，不改任何群組的會議開關。

來源 conversation_key、原始訊息／音檔、Notion 保存位置、共同編輯與任務責任全部保持。只改發布去向，不重製、不搬資料、不改負責人或期限。儲存群組不發 LINE；首次確認發布才送到已選目的群。發布確認明示群名及閱讀／逐字稿／錄音範圍。

新目的群目前成員於 published 後可本人登入只讀與收聽，不增加草稿、編輯、歷程、名錄、詞庫或待辦指派權，也不能新增回覆。不打開公開連結。原來源與原指定分享權限保持；每次閱讀、播放與清單重新核對目的群身分、同 OA／單位及目前成員資格。

開始發布後目的群鎖定；傳送前持久保存目的地、訊息本文及原重試鍵，回覆遺失或重啟不得換群或重複建立 Notion／任務。原始來源證據仍留原處，讓發布去向不會改寫任務來源。
