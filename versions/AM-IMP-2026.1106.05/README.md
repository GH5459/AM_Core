# 空白新增任務先開啟表單

狀態：Ready，尚未發布。正式測量顯示一般新增任務在同仁名單讀完前不能開始輸入。本項只改善沒有既存草稿的一般空白新增：先呈現原表單，允許填寫名稱與工作說明；同仁名單確認完成前，其他操作與送出保持停用。

名單完成後在同一表單補回原選項與本人預設，不覆蓋等待期間輸入。失敗保留文字並可重新讀取；取消後的回覆不能重開表單或改到下一筆。原草稿、待重試建立、待辦指派及其他特殊入口沿原初始化。原登入、權限、保存、附件、HR 與草稿機制保持。

可輸入時間與可儲存時間分開驗證；此項不代表後端資料讀取或正式任務保存已立即完成。完整測試、正式回讀及實測後才標示 Deployed。

18 項可攜測試、完整 Worker/D1 的 14 組表單與 7 組待送恢復情境，以及六套原儲存／附件／留言／建立／快取／下載回歸通過。320、360、390、430、760、1280 寬度與原 390px HR 操作保持。隔離同仁查詢額外延遲 1,200ms，三次可輸入中位數 1,313→69ms；人員確認完成 1,319→1,335ms，後者沒有改善。正式結果另行量測。
