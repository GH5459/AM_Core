# Install

先合併並測試經審查的 AM 主線；取得 DailyLog 當下完整正式模組與設定，保存在私有目錄。依 `tools/prepare-line-task-rules-worker.cjs` 由完整基底產生隔離候選，只替換工作日誌任務入口及相關模組。逐一核對其餘模組、資產、秘密、設定、bindings、排程與 tail；正式發布前重新核對現場版本，若變更則重新取基底及測試。不得由有未提交變更的根目錄或舊包全量發布。

安裝及發布 AM 與 DailyLog 時分別核對目標與回退版本，保留原資料，不重播事件、不代真人登入或發測試業務訊息。各專案依其授權與部署方式獨立安裝，禁止搬移資料。
