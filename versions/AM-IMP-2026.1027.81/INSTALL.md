# 安裝

1. 下載並保存實際目標的最新完整正式模組、目前版本、設定、資產、服務連結與排程；不可全量建立舊 checkout。
2. 用 `build.cjs` 的 `patchWorker` 修改目前 `worker.mjs`，來源守衛不符時停止並檢查最新程式。其餘模組逐一保持原內容。
3. 執行套件單元測試與完整 Worker／本機 D1 測試，核對原任務卡片讀取、修改、完成、版本衝突、撤權與轉派。
4. 程式審查、完整 CI 通過並合併 main 後，重新核對線上版本沒有變動，再上傳與切換實際目標。
5. 如有明確授權的既有指派修正，從原會議工作頁保存修訂，保留原任務 ID、來源、討論及原歷程；核對完成同步。
6. 各獨立服務分別安裝與驗證，不混用資料或金鑰。
