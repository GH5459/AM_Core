# 安裝

1. 從最新 main 隔離實作並通過完整CI，再合併及確認 AM 兩個原站的精確提交。
2. 取得原 DailyLog 真正最新完整模組包、設定與原資料私人快照；精準延伸本包五個後端／介面模組、原入口接線與兩個新模組，其他模組、Assets、秘密、bindings 與兩個 cron 保持。
3. 使用原共享管理連線簽署只限單案的短效請求；每次以原任務服務回核事件或本人明確單案交接。不得將管理憑證交給AI或使用真人session。
4. 原接收器 prompt 備份後增補，保留其他設定；沒有事件不啟動AI，heartbeat維持暫停。
5. 本人本次明確要求的原案件，可建立短效、精確版本的 inspect-and-record 交接，只能讀取及寫查核；不能核准、領執行資格、派發、改期或結案。
