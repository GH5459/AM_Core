# 工作日誌入口接續與開頁讀取

使用者於本聊天核准第 1、2 項優化、工作清單分段查核、部署與前後實測。

LINE 確認後返回現有 /line-entry，保留會議目標。afterConnect 僅選擇既有 /login 備援，不作身分或權限依據；缺少、過期或撤銷 session 仍走原驗證，避免再回 LINE 入口。開頁 profile 僅讀一次，供原 register 與 bootstrap 共用，不跨請求快取。

完整正式 DailyLog 現場模組為基準，只增量修改 worker 與 entry-speed。工作清單只增加請求內分段計時，成功且通過原權限的回應以 Server-Timing 回傳固定名稱與耗時，不包含身分、工作內容、憑證或查詢字串。既有讀取、匯入及回應前權限再核對均保留。

驗證：LINE 返回、失效登入備援、防止循環、匿名／撤權拒絕、完整 Worker-D1、原登入與 CSRF、工作清單相容性。必須由通過 CI 並合併 main 的精確來源發布，核對原 95 模組、設定與資料；不從 dirty 根目錄建置。正式回讀與相同電腦流程三次前後計時後記錄實際結果。原手機 29 秒並非電腦基準。
