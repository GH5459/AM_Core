# 第二步講話者修正與返回設定

狀態：Deployed。PR394 完整檢查 5 分 16 秒通過；AM 正式 ef7579c 兩站與受測程式核對一致，Render 42 秒 Live。原 13 會議／63 待辦內容、負責人及期限保持；本人頁面預覽與設定往返、正式畫面程式的合成套用／保存及手機版面均通過。

- 第二步在「逐字稿與講話者校對」預覽 A／B 交換或修正姓名，同時替換明確的講話者標示，不連續取代造成兩人合併。
- 逐段播放、選擇講話者、預覽及套用。只有唯一相同時間與原講話者的對話依據會跟著更新；無時間或同秒多段時提示另行核對依據。
- 修正先保留在畫面，沿原逐段版本、儲存、衝突比較與修改歷程；未另行編輯或儲存前可復原。
- 主持人在第二步返回設定，不改變 review 狀態，不重新辨識或製作。既有記錄、逐字稿、待辦及未儲存輸入保持；返回第二步後可一起保存。
- 待辦內容、負責人、日期與依據均不參與交換。摘要內一般人名不自動取代，畫面提醒另行核對。
- 播放定位清單依目前逐字稿產生，避免顯示舊講話者；原始辨識結果與錄音仍保留。
