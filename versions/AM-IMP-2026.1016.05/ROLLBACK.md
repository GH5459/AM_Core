# Rollback

Private receipts contain previous immutable versions and module bytes. Do not restore business snapshots or delete intake/work/attachments. Do not overwrite a newer parallel release. A rollback must first reconcile the latest baseline and any pending notified photo plans: older AM does not drain the new photo queue, so preserve or explicitly finish those jobs through the reviewed new worker before runtime rollback. Current editor/attachments and source guards remain authoritative; never replay original group events to compensate.
