# LINE 會議報告分層縮排

LINE 發布不再直接截取網頁用的 Markdown 記錄及長段對話依據。共用 `modules/meetings/line-record.js` 轉為 ● 大主題、○ 子題、◦ 小題及逐層全形縮排；摘要按原句分點，保留原狀態。換行延續縮排，不讓續行退回主題邊界。

內文以各大主題分配篇幅，過長細項明示開啟完整記錄，原對話依據仍在原網頁／Notion。沿原發布通知與重試鍵，只改呈現，不重新派發任務、不修改會議或重送既有通知。一般與備援的舊流程也共用此排版。

契約 meeting-line-indented-outline-v1。目標僅原 AM 平台；私人內容、資料快照及秘密不進 Git，獨立 HOZO_AM／SevenAM 不在安裝範圍。
