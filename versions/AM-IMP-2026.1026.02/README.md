# 工作日誌保存與原會議恢復

本版修正工作日誌整包提交超過舊 1 MiB 限制而被拒絕，以及會議公開網址與管理網址不同造成已接續登入仍被拒絕。沿原保存流程，將日誌入口及自動整理一致提高至 1.5 MiB；原個人歸屬、版本衝突、防重、CSRF、私密隔離與 Notion 同步均保持。容量仍有限，不宣稱無限保存。手機原 outbox 與 ack 格式、內容及清除時機完全沿用。

會議接續採原已登記公開網址，機器服務仍用原管理網址；只接受這兩個精確設定的來源，原身分、專案與來源成員檢查保持。讀取失敗顯示失敗，不顯示成新空白清單。

同來源先重核現有登入，避免 SameSite Cookie 在跨站初次導覽未送出時立即繞其他系統。已有有效會議登入直接回原會議頁；必要跨站驗證仍保留。

發布必須沿最新完整模組包，不能從舊完整包重發。AM 由已合併來源發布；DailyLog 只換 worker 與接續模組、增加狀態文字模組；UOF 只換接續模組。保留原 Assets、秘密、設定、bindings、排程、全部業務資料與權限。

隔離完整 Worker/D1 驗證 1,146,000 bytes 以上內容保存、完整回讀、防重、衝突與錯來源拒絕；實際大小以私人結果檔為準。完整會議服務驗證原清單與 Calendar，六向登入及六寬度瀏覽器驗證通過。正式回讀前不可稱已部署，手機實機驗收須獨立說明。
