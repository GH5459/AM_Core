# 工作日誌「會議」分頁

新增工作類型「會議」，直接開原會議清單、原會議記錄、議程與錄音畫面。日誌、日常與專案仍沿原畫面切換。會議畫面固定保留同一個瀏覽器內容，切換分頁不重建錄音與編輯表單。

個人 Google Calendar 的活動旁加入「會議建檔」。本人原私人來源已開啟且唯一時，一次點擊沿原流程建檔並開啟；來源尚待選擇時，在會議分頁帶入原活動，明確選擇來源後保存。原有建檔識別與重試保持，不另外建立 Google 活動、Notion 會議副本或工作資料庫。

服務端沿現有登入與已確認的雙向 LINE 工作身分。原會議仍檢查當前有效帳號、來源成員、主持人、分享及版本權限。瀏覽器不持有服務秘密，原 Cookie／LINE token 不轉送；二進位上傳按原分段傳送並逐次簽名。

本包為 Ready。正式 Cloudflare 查詢 HTTP 401，現場最新版本尚未回讀，隔離測試使用已保存完整 21baa75c 來源；不是正式部署證據。原上線版本、資料、排程與綁定未改。
