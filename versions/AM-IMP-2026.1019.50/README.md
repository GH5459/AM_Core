# 三入口共用首次公司身分

工作日誌、會議與 UOF 選單先經同一 LINE 本人登入入口。已有一致且有效的 UOF 或 native 工作身分直接沿用；沒有映射者以當次公司帳密驗證並明確確認，才建立共用對應。原帳號、工作使用者、UOF bindings、各功能開通及業務資料保留。

`line-company-common-first-link-v1`。身分保管沿原 UOF 加密 DO，工作對應以同一協調入口防衝突並投影至原 DailyLog 正反向紀錄；舊兩個登入入口也經相同協調。LINE token 限原登入 channel，未知 LINE 不以舊 cookie 或轉傳短票認領。UOF 身分核對不要求簽核開通，簽核業務登入與 Google 授權仍獨立。

來源：ADR-34／E69；使用者已明確要求實作與正式部署。實際發布與回讀狀態以各原目標紀錄為準，本套件存在不等於已正式切換。
