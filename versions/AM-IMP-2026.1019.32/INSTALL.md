# 安裝

1. 以最新 origin/main 及正式完整 DailyLog 為基準，保留其他並行更新。
2. 套用 hub-service.js、hub-ui.js 與 dailylog-meeting-calendar.mjs。沒有新增資料表；原 receipt 與 documents 保存來源／固定目標，原 plan 版本保護邀請名單。
3. DailyLog 只替換最新完整包的 meeting-hub-calendar.mjs，其餘模組、資產、設定、秘密、排程必須前後比對；先更新相容的日曆模組，再發布 AM。UOF 不需重發。
4. 既有工作頁無自動改名單或寫 Google，需主持人明確選擇並保存。HOZO／Seven 需各自獨立安裝與驗證，不複製正式資料。
