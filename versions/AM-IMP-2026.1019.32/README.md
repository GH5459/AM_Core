# Google 行程的內部邀請

從原 Google Calendar 開啟的會議可由主持人獨立儲存內部參與者，列入受邀同仁的我的會議與個人行程，開放既有受邀者的會前資料／共同確認權限。原行程的時間、地點與取消仍在原日曆管理；不額外複製主持人行程，不代邀真人。

Google 同步逐人顯示待同步、已同步、沿用既有行程與失敗原因。以原 iCalUID 及單次發生時間核對受邀者目前目標日曆；已有則只連結、不覆寫或取消原活動；沒有才沿原固定目標與穩定活動 ID 建立。重複儲存／重試不另建。內部邀請獨立於 Google 成功與否。

舊的 Calendar 工作頁在主持人明確保存邀請時，經本人簽章清單找回原行程；不依名稱猜配，不批次遷移既有會議。不推播 LINE、不重建 Notion 或工作任務。
