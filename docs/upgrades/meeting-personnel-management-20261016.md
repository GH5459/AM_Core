# 個人會議移至同仁管理

AM-IMP-2026.1016.07，2026-10-16，Installed。使用者要求將個人與葉小蝸的會議管理移至同仁名下，其餘 group／room 留在 LINE 會議管理頁。

個人會議沿用既有對話設定與待辦模式，在同仁管理／組織同仁管理顯示獨立開關與儲存按鈕。以原 UOF 本人綁定、同一 OA 的對話鍵及最新有效同仁名單對應；不以暱稱猜測，不開通 UOF、日誌或其他權限。未確認對應保留在同仁管理待確認區，不刪對話或修改既有設定。儲存前核對原綁定服務，拒絕停用、撤銷、重複與錯帳號；群組入口也不能寫個人設定。

只在真正最新完整 UOF 的主模組替換會議 UI 附加片段並更新會議管理模組，其餘完整模組與原資產、秘密、DO、設定及排程保持。新增非秘密部署端 OA 對應值，不寫進共用包；不重發 AM、DailyLog、HOZO_AM 或 SevenAM。本次沒有資料遷移，Notion 庫、Drive 錄音、會議文字與開關／模式值保持。

同名、重複綁定、其他 OA、停用同仁、已撤銷、錯入口、CSRF 與原操作轉送測試通過；真正 workerd 的個人／群組範圍及原簽章轉接測試通過。完整 Worker 原登入、最新管理權限與 CSRF 測試通過。完整原管理資產搭配假資料已確認搜尋、分流、原人員草稿保持、個人失敗後重整保留草稿及同操作只寫一次、390 手機版。正式版本與本人只讀畫面仍待發布後查驗，未代送真人 LINE、錄音、任務或個人設定寫入。
