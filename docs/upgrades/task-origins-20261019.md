# 工作日誌任務來源標示

AM-IMP-2026.1019.37。使用者要求清楚顯示會議及 LINE 群組來源，並已明確同意正式發布、保留其他功能資料。

原管理整合驗證後新增 POST /integrations/meeting-management/task-origins。DailyLog 只提交原已授權任務主紀錄對應的會議／群組識別；AM 固定原服務 OA，精確選取已發布會議主題與日期或群組名稱。無會員目錄、訊息、逐字稿或其他會議清單外洩，也不公開此入口給一般瀏覽器。

不修改任務、會議、分享、Notion、LINE、Calendar、設定或排程。舊任務與新任務使用同一路徑；轉派後仍是原來源。來源服務失敗由 DailyLog 保留來源類型並繼續開啟原任務。

本機 PostgreSQL／簽章路由／原對話與完整工作頁流程、DailyLog 完整 Worker／D1 與原個人轉派、六寬度 Chrome 的清單／卡片／長名稱／草稿／重整及零任務寫入通過。正式資料唯讀核對，既有 17 筆會議任務及 25 筆 LINE 任務全部可找到原名稱；個別資料及完整回執另存私有區。

發布須先完整 CI 通過、合併到最新 main 並核對精確提交，再延伸當時最新完整 DailyLog，keep_assets。正式發布結果另補，不以本機通過冒稱已部署。
