# 群組舊邀約停止重試

使用者回報多群持續出現一般自動重試提示，要求未加入者不再重試。正式只讀定位三筆舊meeting/fanout來源；原因為未連結工作身分及Google行事曆未連線，非新交辦task規則失效。

已按原bot、確切三筆來源、原payload版本與無有效租期條件，將這三筆設定為舊版支援的ignored終態並記錄停止原因；原訊息及完整people／calendarResult保持，未刪除已存在行程。稍後回讀三筆attempts不再增加、原來源與成員完全相同。私人完整備份與收據不進Git。

程式修正：未連線不再預覽或等待補登；停止來源仍保留完整原文、分配與回執。正常可處理來源保持原確認與權限。一般暫時故障採60秒／300秒安靜退避，最多三次失敗，之後停止；群組不再收到一般自動重試提示。Google未連線不自動建補件或要求整群登入。

完整隔離群組測試27項通過；完整CI與正式發布待完成。DailyLog／UOF／Rich Menu／權限及設定不改，不送真人測試LINE或建新工作／行程。
