# 會議共同編輯與指定夥伴分享

AM-IMP-2026.1019.01，Installed；正式部署待核對。

使用者確認以觀看版作為編輯版，原對話成員在發布前後均可修改並各自按儲存。會議記錄以穩定段落 ID 及個別版本保護；待辦維持任務編號，內容、原對話曾發言且可確認的成員選單、截止日期直接修改。取消與切換模式保留正常操作，未儲存不自動寫入。

每次修改保存編輯者、顏色、時間、原文及新文；新增以顏色標記，刪除在修改比較中保留。歷程可分批讀取，不只展示最後一次。不同段落的修改可依序加入正式修訂佇列；同處舊版本必須先比較，不靜默覆蓋。正式觀看保留上一個已完成 Notion／原任務同步的版本；原頁、音檔及任務 ID 不變。

分享管理維持主持人權限。新「指定組織夥伴」使用原服務的 UOF 共用有效同仁及組織資料，以帳號辨識同名者；複選、搜尋姓名／單位／工號、顯示與移除選中名單。指定夥伴必須以本人 LINE 驗證原綁定，並重核該服務的有效人員；僅正式內容與錄音可讀，不能編輯、讀歷程、目錄或草稿。原「任何持有連結者」開關獨立保留，預設及既有設定不變。功能不自動傳送通知或建立其他人的任務。

DailyLog 只在真正最新完整 Worker 中新增兩個受原服務驗證的分享路由與 meeting-sharing.mjs，沿原 syncPersonnel；工作日誌未開啟但仍是有效同仁者也可指定，不以工作功能開關代替人員有效身分。所有私人資料／金鑰／原始畫面與完整正式包另存，不進 Git。
