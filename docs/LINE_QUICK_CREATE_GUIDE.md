# LINE 群組任務與行事曆指令

新版統一規則已於2026年11月2日正式啟用；部署證據見 `docs/upgrades/line-group-commands-20261102.md`。

在有小葉的 LINE 群組中，先輸入 @ 並從 LINE 名單選取本人要標註的對象，再接命令詞。直接打名字不算標註。

| 指令範例 | 結果 |
| --- | --- |
| @小美 任務 整理招募資料 | 任務交給小美，發話者保留交辦人身分。 |
| @小美 @阿明 任務 明天盤點用品 | 同一任務交給小美及阿明共同執行。 |
| @小美 活動 明天下午兩點討論招募進度 | 加入發話者及小美的 Google Calendar。 |
| @小美 @阿明 會議 明天下午兩點到三點專案檢討 | 加入發話者、小美及阿明的 Google Calendar。 |
| @小葉 任務 整理資料 | 建立發話者本人的任務。 |
| @小葉 活動 明天下午三點準備報告 | 只加入發話者的 Google Calendar。 |

「活動」和「會議」使用相同排程流程。沒有「任務」「活動」「會議」命令詞的普通 @ 訊息不建立工作。

任務沒寫日期時，執行日為發話當天，截止時間從原訊息發出時刻起算48小時。有執行日期但沒寫截止日時，截止日為執行日後兩天23:59。日期矛盾或工作內容不足會請補充，不自行猜測。補工作內容時，原本的截止時間不會重新起算。

活動或會議缺少名稱、日期或時間時，先補資料：

> 補充活動「專案檢討」：明天下午兩點到三點。

只有一份待補活動時可省略名稱。請由原發起人在原群組補充；補齊後會開始建立。未寫結束時間或長度時預設一小時；地點可以留空。此入口安排日曆活動，不自動產生視訊會議室或會議紀錄。

每個人的結果會分別列出。工作日誌身分、使用資格與本人 Google 連線仍須有效；未成功者不會因稍後登入而自動重播原訊息。已成功者不會重建。結果不明時先查看日曆或原任務，避免另發新指令造成另一筆工作。

任務建立後，可以從工作日誌查看或沿原任務通知回覆修改。回覆原交辦文字的進度仍接續同一任務，不自動標記完成。升級前已發出的確認卡保留原確認與逾時規則；待補活動卡10分鐘內未補齊會取消，修改不延長期限。
